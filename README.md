# استودیو انیمیشن AI 🤖🎬

برنامه دسکتاپ که از روی یک عکس، آواتار می‌سازد و برای سناریوهای مختلف انیمیشن تولید می‌کند.

## موتور AI (سه مرحله، روی خود دستگاه)

1. **تولید آواتار** — Stable Diffusion 1.5 به روش img2img از روی عکس کاربر، آواتار استایلایز می‌سازد (چهره حفظ می‌شود).
2. **کی‌فریم‌های انیمیشن** — برای هر سناریو ۲–۳ ژست با AI تولید می‌شود؛ حرکت بین ژست‌ها با tween کدی ساخته می‌شود (حدود ۱۰ برابر سبک‌تر از ویدیو-دیفیوژن، روی گرافیک‌های معمولی هم اجرا می‌شود).
3. **حذف پس‌زمینه** — مدل سبک u2netp (روی CPU هم سریع است).

**بهینه‌سازی‌ها:** انتخاب خودکار دستگاه (CUDA > DirectML برای AMD/Intel در ویندوز > MPS در مک > CPU)، fp16 روی GPU، فقط ۲۴ استپ در ابعاد ۵۱۲، مدل‌ها فقط بار اول دانلود می‌شوند (داخل پوشه `ai_models` کنار برنامه، بدون نصب هیچ‌چیز روی سیستم).

سناریوها: **در حال کار**، **در انتظار**، **ساخت عکس**. خروجی: گیف ۵۱۲×۵۱۲ با پس‌زمینه شفاف (مناسب اورلی استریم).

## اجرا
```bat
pip install -r requirements.txt
python main.py
```
دکمه «🤖 ساخت آواتار با AI» موتور کامل را اجرا می‌کند (در بیلد کامل). بدون آن، حالت نمایشی (procedural) فعال است.

## گرفتن خروجی ویندوز + مک
1. ریپو بساز و همه فایل‌ها را push کن (شامل `.github/workflows/build.yml` و `build.spec`)
2. ورک‌فلو همزمان روی `windows-latest` و `macos-latest` بیلد می‌کند
3. از تب Actions → آخرین run → بخش Artifacts دانلود کن: `AIAnimator-windows` و `AIAnimator-macos`
4. با تگ `v*` (مثل `v1.0`) ریلیز گیت‌هاب هم ساخته می‌شود

## ساختار
- `main.py` — رابط گرافیکی (PySide6، فارسی و راست‌چین)
- `ai_engine.py` — پایپ‌لاین سه‌مرحله‌ای AI (مدل‌منیجر، انتخاب دستگاه، پرامپت‌ها)
- `scenarios.py` — موتور انیمیشن (procedural + tween کی‌فریم‌های AI)
- `character.py` — آماده‌سازی کاراکتر از روی عکس
- `exporter.py` — خروجی گیف شفاف (فقط Pillow)
- `assets/sample.png` — عکس نمونه
