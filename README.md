# استودیو انیمیشن AI — دمو 🎬

برنامه دسکتاپ که از روی یک عکس، برای سناریوهای مختلف انیمیشن می‌سازد.

## سناریوهای دمو
1. **در حال کار** — کاراکتر پشت میز، تایپ کردن، مانیتور با کد اسکرول‌شونده
2. **در انتظار** — تنفس/تاب ملایم با نقطه‌های چشمک‌زن
3. **ساخت عکس** — نسخه «نقاشی» مشتق‌شده از همان عکس ورودی، که خودش را می‌کشد

خروجی: گیف ۵۱۲×۵۱۲ با پس‌زمینه **شفاف** (مناسب اورلی استریم)، ۱۵ فریم‌برثانیه، لوپ ۴ ثانیه‌ای.

## اجرا (ویندوز)
```bat
pip install -r requirements.txt
python main.py
```
هیچ نصب اضافه‌ای روی سیستم لازم نیست؛ همه‌چیز داخل exe باندل می‌شود.

## گرفتن exe از گیت‌هاب
1. یک ریپوی جدید بساز (مثلاً `AI-Animator`)
2. همه فایل‌های این پوشه را push کن (شامل `.github/workflows/build.yml`)
3. بعد از پایان workflow، از تب **Actions** → آخرین run → بخش **Artifacts** فایل `AIAnimator-windows` را دانلود کن

## ساختار
- `main.py` — رابط گرافیکی (PySide6، فارسی و راست‌چین)
- `scenarios.py` — موتور سه سناریوی انیمیشن
- `character.py` — آماده‌سازی کاراکتر و نقاشی از روی عکس
- `exporter.py` — خروجی گیف شفاف (فقط Pillow)
- `assets/sample.png` — عکس نمونه برای اجرای فوری دمو
